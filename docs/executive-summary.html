POM (purchase order management)
ระบบจัดการขายแบบสินเชื่อสำหรับ Rimping

ภาพรวมโปรเจค

POM (purchase order management) คือระบบหลังบ้าน (Back-office) สำหรับจัดการ Purchase Order (PO) ที่ขายสินค้าแบบเครดิตให้ลูกค้า ครอบคลุมตั้งแต่การออก PO, ติดตามสถานะ, ออกใบแจ้งหนี้, บันทึกการชำระเงิน พร้อมระบบแจ้งเตือนอัตโนมัติผ่าน LINE

ระดับสิทธิ์ผู้ใช้งาน
เจ้าหน้าที่: ออก PO บันทึกการชำระเงิน ดูรายงาน

ผู้ดูแลระบบ: จัดการลูกค้า ปรับวงเงินเครดิต อนุมัติคำขอเพิ่มวงเงิน

เทคโนโลยีที่ใช้

ระบบพัฒนาด้วยเทคโนโลยีเว็บสมัยใหม่ที่รองรับการทำงานบนมือถือและคอมพิวเตอร์ ใช้ฐานข้อมูล MySQL เก็บข้อมูลอย่างปลอดภัย มีระบบแจ้งเตือนผ่าน LINE และรองรับการเชื่อมต่อกับระบบอื่นในอนาคต

ฟีเจอร์หลัก

  • ออกใบสั่งซื้อ (PO) พร้อมตรวจสอบวงเงินเครดิตอัตโนมัติ
  • ติดตามสถานะสินค้าตั้งแต่รอจัดส่งจนถึงลูกค้ารับของ
  • ออกใบแจ้งหนี้และบันทึกรับชำระเงินพร้อมแนบหลักฐาน
  • แก้ไขข้อมูลได้พร้อมบันทึกประวัติการแก้ไขทุกครั้ง
  • แดชบอร์ดสรุปยอดลูกหนี้และรายการที่เลยกำหนดชำระ
  • แบ่งระดับสิทธิ์ผู้ใช้งาน: เจ้าหน้าที่และผู้ดูแลระบบ
  • พิมพ์เอกสารและส่งออก PDF ได้
  • ใช้งานได้ทั้งบนมือถือและคอมพิวเตอร์

การนำ AI และระบบอัตโนมัติเข้ามาใช้

AI READY

1. ระบบให้คะแนนความน่าเชื่อถือลูกค้า พร้อมใช้งาน

ระบบเตรียมพร้อมรองรับ AI วิเคราะห์ประวัติการชำระเงินของลูกค้า เพื่อให้คะแนนความน่าเชื่อถือ ช่วยพิจารณาวงเงินเครดิตที่เหมาะสม

AUTOMATION

2. แจ้งเตือนอัตโนมัติผ่าน LINE ใช้งานอยู่

ระบบส่งข้อความแจ้งเตือนไปยังผู้บริหารและเจ้าหน้าที่อัตโนมัติ ตรวจสอบลูกค้าเลยกำหนดชำระทุกวัน เวลา 08:00 และ 14:00 น.

  • แจ้งเตือนลูกค้าเลยกำหนดชำระ 3, 7, 14, และ 30 วัน
  • แจ้งเตือนเมื่อมีลูกค้าใหม่เข้าระบบ
  • แจ้งเตือนการขอเพิ่มวงเงินเครดิต
  • แจ้งเตือนการปรับเปลี่ยนวงเงินลูกค้า
RPA INTEGRATION

3. เชื่อมต่อระบบคลังสินค้า Mock Ready

เตรียมเชื่อมต่อกับระบบจัดการคลังสินค้า (JDA) เพื่อส่งข้อมูลการสั่งซื้อเข้าระบบโดยอัตโนมัติ ลดการทำงานซ้ำซ้อน

ประโยชน์ที่ได้รับ

  • ลดเวลาการติดตามลูกหนี้ด้วยการแจ้งเตือนอัตโนมัติ
  • ลดความเสี่ยงการให้เครดิตเกินวงเงินด้วยการตรวจสอบอัตโนมัติ
  • ตรวจสอบยอดค้างและประวัติลูกค้าได้แบบ Real-time
  • ออกเอกสารได้รวดเร็ว ไม่ต้องทำซ้ำหลายครั้ง
  • ทำงานได้จากทุกที่ ทั้งบนมือถือและคอมพิวเตอร์

สรุปสำหรับผู้บริหาร

POM (purchase order management) เป็นระบบจัดการขายแบบเครดิตแบบครบวงจร ช่วยให้เจ้าหน้าที่ติดตามสถานะการสั่งซื้อและการชำระเงินได้อย่างมีประสิทธิภาพ ลดการทำงานด้วยมือด้วยระบบแจ้งเตือนอัตโนมัติผ่าน LINE พร้อมรองรับการประเมินความเสี่ยงด้วย AI ในอนาคต
