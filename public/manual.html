1 ภาพรวมระบบ

FlowSync คือระบบหลังบ้านสำหรับจัดการการขายสินค้าแบบสินเชื่อให้ลูกค้า ครอบคลุมตั้งแต่การออก PO ตรวจวงเงิน ติดตามสถานะการจัดส่ง บันทึกการชำระเงิน ไปจนถึงพิมพ์ใบแจ้งหนี้

ระบบช่วยอะไรได้บ้าง

  • 📝 ออก PO พร้อมตรวจวงเงินสินเชื่อ (credit limit) ก่อนออกอัตโนมัติ
  • 📦 ติดตามขั้นตอน ตั้งแต่ร่าง → ยืนยัน → แพ็ค → ตรวจ → จัดส่ง → ลูกค้ารับของ
  • 💵 ออกใบแจ้งหนี้ + บันทึกการชำระเงิน (จ่ายเต็มหรือบางส่วนก็ได้) + แนบสลิปรูป
  • ✏️ แก้ไข PO ได้ตราบที่ยังไม่ชำระครบ พร้อมบันทึก audit log ทุกครั้ง
  • 📊 Dashboard สรุปลูกหนี้คงค้าง วงเงินใช้ไป PO เกินกำหนด
  • 🖨️ พิมพ์เอกสาร A4 ใบเสนอราคา/ใบแจ้งหนี้ ส่งออก PDF ได้ทันที

โครงสร้างเมนูหลัก

ลูกค้า รายการลูกค้าทั้งหมด พร้อมวงเงินและลูกหนี้คงค้าง
Purchase Orders รายการ PO ทั้งหมด กรองได้ตามสถานะและวันที่
+ สร้าง PO (ปุ่ม FAB) ปุ่มสีเขียวกลม สร้าง PO ใหม่ได้ทุกหน้า

2 การเข้าสู่ระบบ & สิทธิ์การใช้งาน

ระบบมีผู้ใช้ 2 ระดับ: admin (ทั่วไป) และ super_admin (สิทธิ์เต็ม)

ขั้นตอน login

  1. เปิด browser ไปที่ http://localhost:3000/login
  2. กรอก Username หรือ Email และ Password
  3. กดปุ่ม เข้าสู่ระบบ — ระบบจะพาเข้าหน้า Dashboard

บัญชีเริ่มต้น (Default credentials)

Username Password ระดับ สิทธิ์
admin Admin@123 admin ทุกฟังก์ชัน ยกเว้น เพิ่ม/แก้ไขข้อมูลลูกค้า
superadmin SuperAdmin@123 super_admin ทุกฟังก์ชัน รวมถึงเพิ่ม/แก้ไขลูกค้า
⚠️ ความปลอดภัย เปลี่ยน password ทันทีหลังใช้งานครั้งแรกในสภาพแวดล้อม production

3 หน้า Dashboard

หน้าแรกหลัง login แสดงภาพรวมของระบบในจุดเดียว

การ์ดสรุป (KPI)

  • ลูกหนี้รวม — ยอดที่ลูกค้าทุกรายค้างชำระอยู่
  • PO เปิดอยู่ — จำนวน PO ที่ยังไม่ปิดงาน (ยังไม่ received)
  • PO เกินกำหนดชำระ — PO ที่ due_date ผ่านมาแล้วแต่ยังไม่ paid
  • มูลค่าขายเดือนนี้ — รวมยอด PO ที่สร้างในเดือนปัจจุบัน

ตาราง PO ล่าสุด

แสดง 10 รายการล่าสุด คลิกที่ PO number เพื่อเข้าหน้ารายละเอียด

4 การจัดการลูกค้า

เมนู ลูกค้า — ดู/เพิ่ม/แก้ไขข้อมูลและวงเงินสินเชื่อ

4.1 ดูรายการลูกค้า

ทุก role ดูได้ — แต่ละแถวแสดง:

  • ชื่อ + รหัสลูกค้า + ผู้ติดต่อ
  • วงเงินสินเชื่อ (credit_limit)
  • ลูกหนี้คงค้าง + แถบสถานะการใช้วงเงิน (เขียว/เหลือง/แดง)
  • วงเงินคงเหลือ = limit − outstanding
  • Credit Score 0–1000 (เตรียมไว้ให้ AI ประเมิน)

4.2 เพิ่มลูกค้าใหม่ super_admin เท่านั้น

  1. เข้าเมนู ลูกค้า → กดปุ่ม + เพิ่มลูกค้า (มุมขวาบน)
  2. กรอกข้อมูล: ชื่อกิจการ ผู้ติดต่อ โทรศัพท์ Email เลขผู้เสียภาษี ที่อยู่
  3. กำหนด วงเงินสินเชื่อ (บาท) และ เครดิต (วัน) เริ่มต้น เช่น 7/15/30/60
  4. กรอก Credit Score 0–1000 และหมายเหตุ (ถ้ามี)
  5. กด บันทึก — ระบบจะพาไปหน้ารายละเอียดลูกค้าทันที
💡 admin ทั่วไป ถ้าไม่ใช่ super_admin จะไม่เห็นปุ่ม "+ เพิ่มลูกค้า" และเข้า URL ตรงๆ ก็ถูก redirect กลับ พร้อมแบนเนอร์เตือน

4.3 แก้ไขข้อมูลลูกค้า super_admin เท่านั้น

  1. เข้าหน้ารายละเอียดลูกค้า (กดที่ชื่อในรายการ)
  2. กดปุ่ม แก้ไขข้อมูล มุมขวาบน
  3. ปรับฟิลด์ที่ต้องการ — ชื่อ ที่อยู่ วงเงิน เครดิตเริ่มต้น Credit Score ฯลฯ
  4. กด บันทึกการเปลี่ยนแปลง

5 สร้าง Purchase Order

ออก PO ใหม่ พร้อมตรวจวงเงินก่อนบันทึกอัตโนมัติ

  1. กดปุ่มกลม + ตรงกลาง bottom nav (มือถือ) หรือ + สร้าง PO (เดสก์ท็อป)
  2. เลือก ลูกค้า — dropdown จะแสดงวงเงินที่เหลือของแต่ละราย
  3. เลือก เครดิต (วัน) — ค่า default จะดึงจากลูกค้า สามารถเปลี่ยนได้
  4. เพิ่ม รายการสินค้า: ชื่อสินค้า รายละเอียด จำนวน หน่วย ราคา/หน่วย
  5. กดปุ่ม + เพิ่มรายการ เพื่อเพิ่มอีก หรือกด ✕ เพื่อลบ
  6. ตรวจสอบ ยอดรวม ด้านล่าง
  7. กรอก หมายเหตุ (ถ้ามี)
  8. กด บันทึก PO — สถานะเริ่มต้นจะเป็น draft
🚫 เกินวงเงิน ถ้ายอด PO + ลูกหนี้คงค้างเดิม > วงเงิน จะมีกล่องแดงเตือนและปุ่มบันทึกจะถูก disable

6 การติดตามสถานะ PO

PO ทุกใบจะเดินตามขั้นตอน 7 สถานะ เริ่มจาก draft จบที่ received

draft → confirmed → packed → checked → delivered → received

ความหมายแต่ละสถานะ

สถานะ ความหมาย ปุ่มกด
draftร่าง — ยังไม่ส่งให้ลูกค้ายืนยันยืนยัน PO
confirmedลูกค้ายืนยันแล้ว เตรียมแพ็คได้แพ็คของแล้ว
packedแพ็คเสร็จ รอตรวจตรวจของครบแล้ว
checkedตรวจครบ พร้อมส่งจัดส่งแล้ว
deliveredของออกจากคลัง — ระบบตั้ง due_date ให้อัตโนมัติลูกค้ารับของแล้ว
receivedลูกค้ารับเรียบร้อย รอชำระเงิน—
📅 due_date คำนวณจาก วันที่ delivered + จำนวนวันเครดิต ตอนเปลี่ยนสถานะเป็น delivered/received เท่านั้น

การยกเลิก PO

กดปุ่ม ยกเลิก PO ได้ทุกสถานะก่อน received — สถานะจะกลายเป็น cancelled และล็อกแก้ไขไม่ได้

7 แก้ไข PO & ประวัติการแก้ไข

ตราบที่ยังไม่ชำระครบ สามารถแก้ไขรายการและเงื่อนไขได้

เงื่อนไขการแก้ไข

  • ✅ payment_status เป็น unpaid หรือ partial → แก้ได้
  • ❌ payment_status เป็น paid (ชำระครบ) → ปุ่มจะเทาและกดไม่ได้

ขั้นตอนการแก้ไข

  1. เข้าหน้ารายละเอียด PO
  2. กดปุ่ม แก้ไข PO มุมขวาบน (ข้างปุ่มดาวน์โหลดใบเสนอราคา)
  3. ปรับ: เครดิต (วัน), หมายเหตุ, รายการสินค้า (เพิ่ม/ลบ/แก้)
  4. ระบบคำนวณ คงค้างใหม่ = ยอด PO ใหม่ − ที่ชำระไปแล้ว
  5. กด บันทึกการเปลี่ยนแปลง
⚠️ ข้อจำกัด
  • ยอดรวมใหม่ ห้ามต่ำกว่า ยอดที่ชำระไปแล้ว
  • คงค้างใหม่ + คงค้างของ PO อื่น ห้ามเกิน วงเงินลูกค้า
  • เปลี่ยนลูกค้าหลังออก PO ไม่ได้

ประวัติการแก้ไข (Audit Log)

ทุกครั้งที่กด "บันทึกการเปลี่ยนแปลง" ระบบจะเก็บ snapshot ก่อน-หลังให้อัตโนมัติ ดูได้ที่ส่วนล่างของหน้า PO

  • 📜 ส่วน "ประวัติการแก้ไข PO" แสดงรายการการแก้ทั้งหมด
  • กดที่แต่ละรายการเพื่อขยายดู diff — เปรียบเทียบ ก่อน vs หลัง ในตารางคู่กัน
  • แต่ละรายการแสดง: ผู้แก้ไข, วันเวลา, สรุปการเปลี่ยนแปลง

8 บันทึกการชำระเงิน & แนบสลิป

รับชำระได้ทั้งเต็มจำนวนหรือบางส่วน (จ่ายเป็นงวดได้)

ขั้นตอน

  1. เข้าหน้า PO ที่ต้องการบันทึกชำระ
  2. กดปุ่ม บันทึกการชำระเงิน (ในส่วน Workflow & Actions)
  3. กรอก ยอดที่ชำระ — ค่า default คือยอดคงค้างทั้งหมด ปรับลดได้
  4. เลือก วันเวลาที่ชำระ และ วิธีชำระ (โอน/เงินสด/เช็ค)
  5. กรอก เลขอ้างอิง (transaction ref / เลขเช็ค)
  6. กดที่กรอบเส้นประ "กดเพื่อเลือกไฟล์ / ถ่ายรูปสลิป" เพื่อแนบสลิป
  7. ระบบจะแสดงรูปตัวอย่างทันที กดไอคอน ✕ เพื่อเปลี่ยนรูปได้
  8. กรอกหมายเหตุ (ถ้ามี) → กด บันทึก
📱 มือถือ ระบบรองรับ capture="environment" — กดแล้วเปิดกล้องหลังให้ถ่ายสลิปตรงได้เลย ไม่ต้องบันทึกรูปก่อน

การคำนวณ

  • หลังบันทึก: paid_amount += ยอดที่จ่าย, remaining_amount −= ยอดที่จ่าย
  • ถ้า remaining = 0 → payment_status เปลี่ยนเป็น paid อัตโนมัติ
  • ถ้า paid > 0 แต่ < total → partial

ดูประวัติการชำระ

ตาราง "ประวัติการชำระเงิน" ที่ส่วนล่างของหน้า PO แสดง:

  • วันที่ + ยอด + วิธี + เลขอ้างอิง + หมายเหตุ
  • คอลัมน์ "สลิป" แสดง thumbnail รูปสลิป — คลิกเพื่อดูเต็ม
  • ถ้าแนบ PDF จะแสดงเป็นลิงก์ "ดูไฟล์ (PDF)"

9 ใบเสนอราคา / ใบแจ้งหนี้ (พิมพ์ & PDF)

ระบบสร้างเอกสาร A4 พร้อมสำหรับพิมพ์หรือส่งออกเป็น PDF

9.1 ใบเสนอราคา (Quotation)

  1. เข้าหน้า PO → กดปุ่ม ดาวน์โหลดใบเสนอราคา (มุมขวาบน)
  2. เปิดเป็น tab ใหม่แสดงเอกสาร A4
  3. กดปุ่ม 📥 พิมพ์ / Export PDF หรือ Ctrl+P
  4. ใน print dialog เลือก "Save as PDF"

9.2 ใบแจ้งหนี้ (Invoice)

  1. เข้าหน้า PO ที่มีการชำระอย่างน้อย 1 ครั้ง
  2. กดปุ่ม สร้างใบแจ้งหนี้
  3. ระบบจะสร้างเลข INV ใหม่และเปิดเอกสารใน tab ใหม่
  4. พิมพ์/ส่งออก PDF เหมือนข้อ 9.1
🖨️ Tip การพิมพ์ ในกล่อง print dialog → More settings → uncheck "Headers and footers" เพื่อไม่ให้มีวันที่/URL ติดบนกระดาษ (ระบบตั้ง @page margin: 0 ให้แล้ว ส่วนใหญ่จะหายเอง)

10 คำถามที่พบบ่อย (FAQ)

Q: ทำไมเพิ่มลูกค้าใหม่ไม่ได้?

A: เฉพาะ super_admin เท่านั้นที่เพิ่มได้ — ติดต่อผู้ดูแลระบบเพื่อยกระดับสิทธิ์ หรือให้ super_admin เพิ่มแทน

Q: PO ที่ชำระครบแล้วต้องการแก้ไขทำอย่างไร?

A: ระบบล็อกการแก้ไข PO ที่ชำระครบเพื่อรักษาความถูกต้องของบัญชี — ถ้าจำเป็นจริงๆ ต้องคืนเงินก่อน (ลบรายการชำระล่าสุด) จึงจะแก้ไขได้

Q: บันทึกชำระผิด ต้องการลบทำอย่างไร?

A: เวอร์ชันปัจจุบันยังไม่มีปุ่มลบใน UI — ติดต่อผู้ดูแล database เพื่อแก้ไข (จะมีในเวอร์ชันต่อไป)

Q: รูปสลิปแสดงเป็น "—" ดูไม่ได้

A: ตรวจว่าโฟลเดอร์ public/uploads/slips/ มีไฟล์อยู่ และ environment variable UPLOAD_DIR ตั้งถูกต้อง

Q: เครดิต Score คืออะไร ใช้ทำอะไร?

A: ฟิลด์ 0–1000 เตรียมไว้ให้ระบบ AI ประเมินความน่าเชื่อถือลูกค้าในอนาคต ตอนนี้กรอกเองได้ที่หน้าแก้ไขลูกค้า

Q: ลืม password ทำอย่างไร?

A: ติดต่อ super_admin ให้ reset ผ่าน database โดยตรง (เวอร์ชันต่อไปจะมี UI reset password)

Q: ระบบรองรับมือถือไหม?

A: รองรับเต็มที่ — มี bottom navigation พร้อม FAB สีเขียวกลางจอสำหรับสร้าง PO เร็วๆ และทุกตารางแปลงเป็น card view บนจอเล็ก
